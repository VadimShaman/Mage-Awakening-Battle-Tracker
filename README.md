\# Mage: The Awakening — Battle Tracker

\*\*Интерактивный боевой трекер для Хроник Тьмы (Маг: Пробуждение 2-е издание).\*\*

🌐 Сайт доступен по адресу https://vadimshaman.github.io/Mage-Awakening-Battle-Tracker/ 

\## 📌 Возможности

\- 🎲 \*\*Пул d10\*\* — успех на 8, 9, 10, взрывы десяток.

\- 🧙 \*\*Карточки магов\*\* — Гнозис, Мана, Таинства, Состояния.

\- ⚔️ \*\*Боевой трекер\*\* — инициатива (1d10 + Лов + Сам), урон (тупой/летальный), здоровье.

\- 🔮 \*\*Калькулятор заклинаний\*\* — Охваты, Мана, Парадокс, факторы.

\- 🔥 \*\*Реальное время\*\* — Firebase Firestore.

\- 📥 \*\*Экспорт/импорт лога\*\* — сохранение истории боя в JSON.

\## 🛠️ Технологии

\- HTML5 / CSS3 (тёмная мистическая тема)

\- Vanilla JavaScript (ES Modules)

\- Firebase Firestore (реалтайм)

\- GitHub Pages (хостинг)
